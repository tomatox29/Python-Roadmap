# Data Types in Python

## What are Data Types?

A data type defines the kind of value a variable can store.

Python automatically determines the data type when a value is assigned.

---

## Why are Data Types Important?

- Store different kinds of information.
- Perform appropriate operations.
- Improve readability.
- Prevent programming errors.

---

## Built-in Data Types

### Numeric

- int
- float
- complex

### Boolean

- bool

### Sequence

- str
- list
- tuple

### Set

- set

### Mapping

- dict

### Special

- NoneType

---

## Checking Data Types

Use the `type()` function.

Example:

```python
x = 10
print(type(x))
```

Output:

```
<class 'int'>
```

---

## Summary

Python is dynamically typed.

You do not need to specify the data type manually.

Python decides it automatically based on the assigned value.
